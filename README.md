# bbqr-cli

This is currently a work in progress. Currently you can use it to split a file into a animated BBQr, you can view the
animated QR code in the terminal or you can create images of the QR codes.

## Installation

Currently you need to build the binary yourself. You can do this by running `cargo build --release` in the root of the
project.

Or you can use the locall release script with `./local-release.sh`. It will build and copy the binary to the `$HOME/.local/bin` folder
